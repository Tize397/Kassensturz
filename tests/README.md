# Tests für die Belegerkennung

`pruefen.html` liest 44 nachgebaute Beispiel-Bons mit der aktuellen Erkennung aus und vergleicht das Ergebnis mit dem richtigen.
Aufruf im Browser: `https://deinname.github.io/kassensturz/tests/pruefen.html`

- Enthält nur erfundene Bons, keine echten Daten.
- Ändert nichts an den Daten in der App.
- Nach jeder Änderung an der Erkennung sollten alle Belege grün sein.
